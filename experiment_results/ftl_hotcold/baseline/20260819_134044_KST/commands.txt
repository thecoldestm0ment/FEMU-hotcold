FEMU corrected no-separation baseline reproducibility commands

Source and build
----------------
git switch hotcold/base
git rev-parse HEAD
ninja -C build-femu qemu-system-x86_64
cp hw/femu/scripts/run-blackbox.sh build-femu/run-blackbox.sh

Guest safety gate
-----------------
sudo -n /usr/sbin/blockdev --getsize64 /dev/nvme0n1
findmnt /dev/nvme0n1
test ! -e /dev/nvme0n1p1

Preconditioning and measurement boundary
----------------------------------------
sudo -n /usr/bin/fio --name=fill --filename=/dev/nvme0n1 --direct=1 --ioengine=libaio --rw=write --bs=1M --iodepth=32 --numjobs=1 --size=6G --group_reporting=1
printf BASE | sudo -n /usr/bin/dd of=/dev/nvme0n1 bs=4 count=1 conv=notrunc status=none
printf BASE | sudo -n /usr/bin/dd of=/dev/nvme0n1 bs=4 count=1 conv=notrunc status=none
sync
sudo -n /usr/sbin/nvme admin-passthru /dev/nvme0 --opcode=0xef --cdw10=5

Measurement
-----------
sudo -n /usr/bin/fio --name=baseline --filename=/dev/nvme0n1 --offset=1G --size=4G --direct=1 --ioengine=libaio --rw=randwrite --bs=16k --iodepth=128 --numjobs=32 --time_based=1 --runtime=300 --random_distribution=zipf:0.99 --randrepeat=1 --randseed=20260819 --group_reporting=1
sync
sudo -n /usr/sbin/nvme admin-passthru /dev/nvme0 --opcode=0xef --cdw10=5
sudo -n /usr/sbin/poweroff
